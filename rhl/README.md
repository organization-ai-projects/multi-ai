# RHL - Rust High Level Language Support

Extension VSCode pour le langage RHL (Rust High Level).

## Fonctionnalités
- Coloration syntaxique
- Validation du code (linting)
- Support du serveur LSP
- Auto-complétion

## Commandes
- `.rhl` : fichiers source RHL
- `function` : définition de fonction
- `serialize_*` : sérialisation de données
- `deserialize_*` : désérialisation de données

## Installation

1. Installer les dépendances :
```bash
pnpm install
```

2. Installer l'extension dans VSCode :
```bash
pnpm vscode:install
```
